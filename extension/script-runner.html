Parrot Script Runner (실험용 0.9.0)

수동 실행만 지원합니다.

AI 대화의 링크나 코드가 자동 실행되지 않습니다. 승인된 JavaScript는 지정한 ChatGPT 대화 페이지를 변경할 수 있습니다. 비밀번호·키·쿠키를 코드에 넣지 마세요. 브라우저 확장 설정에서 Allow User Scripts를 켜야 합니다.

실행

해당 대화가 열린 Chrome 탭이 정확히 하나인지 검사합니다. 실행 버튼을 직접 클릭했을 때만 해당 탭에서 한 번 실행합니다.

Chrome API가 반환돼도 페이지 동작이 실제 성공했는지는 별도 확인해야 합니다. 응답이 불확실하면 동일 요청을 자동 재실행하지 않습니다.
