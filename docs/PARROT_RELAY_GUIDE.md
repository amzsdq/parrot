# Parrot Relay Guide

Parrot의 작업 상태와 완료 기준은 `docs/MILESTONES.md`가 유일한 기준입니다. 이 문서는 반복 실행 방식만 설명합니다.

매 실행에서는 먼저 이 문서와 `docs/MILESTONES.md`를 읽고, 필요할 때만 `docs/DEVELOPMENT_CHECKPOINT.md`와 현재 작업에 직접 필요한 자료를 확인합니다. 현재 milestone에서 할 수 있는 실제 작업을 계속 진행하고, 한 항목이 빨리 끝나면 다음 안전한 작업을 바로 이어서 합니다. 외부 증거나 인증된 브라우저가 필요한 항목은 통과한 것으로 처리하지 말고, 기다리는 동안 다음 milestone의 안전한 선행 작업이나 검증·정리 작업을 진행합니다.

한 번의 실행은 실제 작업 약 14분을 목표로 합니다. 시간을 채우려고 기다리거나 의미 없는 일을 만들지는 않습니다. 시작할 때 기존 canonical 예약의 다음 실행을 약 14분 뒤로 잡아 연속성을 확보합니다. 현재 canonical ID는 `6ab40d9986888191ad38dae534417627`이며 새 예약을 만들지 않습니다.

14분보다 일찍 실행이 끝났다면 정상 완료로 보지 않습니다. 왜 조기에 끝났는지 원인을 고치고, 다음 실행이 멀리 남아 있지 않도록 기존 예약을 실제 종료 시각에서 3분 뒤로 당깁니다.

실행이 끝날 때는 다음 사람이 바로 이어서 일할 수 있도록 기존 예약의 prompt 전체를 짧은 자연어 작업지시로 바꿉니다. prompt에는 긴 상태표나 규칙 원문을 복사하지 않습니다. 어떤 GitHub 문서를 읽을지, 무엇을 이어서 할지, 이번 실행에서 최소 어디까지 진행할지, 막히면 대신 무엇을 할지, 14분 기준과 조기 종료 시 +3분 규칙, 그리고 같은 canonical 예약을 계속 쓴다는 정도만 적습니다.

상세 상태와 acceptance는 예약 prompt가 아니라 GitHub에서 다시 읽습니다. BATON, TODO, STATE 같은 별도 작업 권위 파일은 만들지 않습니다. 사용자가 일시정지하면 그 상태를 유지합니다.
